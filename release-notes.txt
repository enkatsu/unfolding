RELEASE NOTES


0.9.97 - 4 October 2026
-----------------------------

Bug fixes
- Fixed zoomAndPanTo() with tweening ending at the wrong location (the more the higher the zoom level), and the
  map moving back and forth while animating. #20
- When dragging across side-by-side maps, only the map the drag started on is panned. #21
- getNearestMarker() returns lines and polygons the mouse is on. #22
- mapChanged() is also called when the map is changed directly, e.g. with panTo(), zoomToLevel() or
  zoomAndPanTo(). #23
- Fixed log4j warnings in the Processing console. #24

Changes
- getDistanceTo() of line and polygon markers returns the distance to the nearest edge (0 inside polygons) instead
  of the distance to the centroid. Use GeoUtils.getDistance(location, marker.getLocation()) for the latter.
- mapChanged() is called for direct map changes, too. Sketches changing the map on every frame, e.g. with panBy(),
  now get mapChanged() calls on every frame.
- If log4j is not configured (e.g. in Processing), only warnings and errors of Unfolding are printed.


0.9.96 - 4 October 2026
-----------------------------

Bug fixes
- Fixed maps with the default JAVA2D renderer, which ignored the map's position and size, hid anything drawn
  before or after the map, and did not show markers. #12
- Maps are no longer moved by the sketch's imageMode, e.g. imageMode(CENTER).
- Tiles that could not be loaded, e.g. due to a timeout, are loaded again after a delay instead of staying blank.
  See AbstractMapDisplay.maxTileLoadAttempts and tileRetryDelayMillis. #14
- Fixed MBTiles with high zoom levels only showing a black screen. #16
- Fixed a resource leak when loading MBTiles.

Features
- MBTilesMapProvider uses the MBTiles metadata (minzoom, maxzoom, center, bounds) to restrict the zoom range of
  maps, and to show the area with tiles initially.
- Added AbstractMapProvider.minZoomLevel(), defaultLocation() and defaultZoomLevel().

Other
- Replaced log4j 1.2.15 with reload4j 1.2.26, a drop-in replacement with the known vulnerabilities fixed.
- A missing SQLite JDBC driver for MBTiles is reported once, with a download link.


0.9.95 - 3 October 2026
-----------------------------

Bug fixes
- Fixed MapBox.BlankProvider. The transparent tile is created locally now.
- Fixed EsriProvider.OceanBasemap, which moved to Ocean/World_Ocean_Base.
- Restricted the zoom range of EsriProvider.WorldPhysical (8), WorldTerrain (9), WorldShadedRelief (13)
  and OceanBasemap (16) to the levels with map data.
- Fixed examples that used providers requiring an API key.

Features
- Added MapBox.StyleProvider for the current Mapbox API (access token required), with the styles
  Streets, Outdoors, Light, Dark, Satellite and SatelliteStreets.
- Added API key support to OpenWeatherProvider.
- Added EsriProvider.WorldDarkGrayCanvas.
- Added Simple3DMapApp example.

Other
- Deprecated providers whose tile servers no longer exist: AcetateProvider, ImmoScout, MapQuestProvider,
  OpenMapSurferProvider, Yahoo, EsriProvider.DeLorme, OpenStreetMap.CloudmadeProvider,
  OpenWeatherProvider.PressureContour, and MapBox.WorldLightProvider, ControlRoomProvider and LacquerProvider.
- Deprecated Google providers, which use unofficial tile URLs not permitted by Google's Terms of Service.
- Normalized line endings to LF.


0.9.94 - 3 October 2026
-----------------------------

Bug fixes
- Fixed loading tiles from OpenStreetMap, which blocks requests without an identifying User-Agent.
  Set TileLoader.userAgent to identify your own application.
- Fixed loading tiles from servers that redirect from HTTP to HTTPS.
- Error responses of tile servers are no longer shown as tiles.
- Fixed examples that used Stamen tiles or the defunct bike-stats API.

Features
- Changed the default provider to EsriProvider.WorldGrayCanvas, as CARTO's Positron requires an API key.
- Added API key support for CARTO, Stadia Maps (Stamen) and Thunderforest providers.
- Moved StamenMapProvider to Stadia Maps.
- Added AbstractMapProvider.maxZoomLevel() to restrict the zoom range of maps to the provider's levels.
- Deprecated OpenStreetMap.OSMGrayProvider.

Other
- Removed the Ant build. The Java examples and tests are built with Gradle now.
